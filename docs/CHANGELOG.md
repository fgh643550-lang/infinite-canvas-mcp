# 更新记录

## v1.0.0 — 2026-11-11

- Windows 原生离线无限画布，支持图片、文字、箭头、小地图和独立存档。
- 新增独立 EXE 形式的 MCP stdio 桥接，无需额外运行时依赖。
- 新增带随机 Bearer 密钥的本机 HTTP REST API，提供 10 个画布工具。
- 批量修改原子提交、一步撤销；版本校验避免覆盖中途发生的修改。
- 新增未保存切换保护、模态对话框保护和请求参数校验。
- 保留旧 `.canvas` 格式、内嵌图片、恢复草稿和备份保存。
- 提供中文配置生成器与接入说明。

验证：17 项核心测试、3 项原生窗口回归、12 项（含分组）端到端测试通过。旧的置顶原生检查在当前环境中新旧版本均失败，未宣称通过；编译保留一个原有过时 API 警告。
